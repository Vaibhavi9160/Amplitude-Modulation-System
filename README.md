# Amplitude Modulation System using Arduino
## Overview

This project demonstrates the implementation of Amplitude Modulation (AM) using embedded hardware and signal processing concepts. The system generates a carrier signal and a modulating signal, combines them to produce an amplitude-modulated waveform, and displays the output using an oscilloscope.

The project helps in understanding the fundamentals of analog communication systems and waveform analysis in real time.
## Components Used
- Arduino UNO
- Breadboard
- Jumper Wires
- Oscilloscope
- Resistors
- USB Cable
## Technologies Used
- Embedded C
- Arduino IDE
- Signal Processing
## Working Principle
Amplitude Modulation (AM) is a modulation technique in which the amplitude of the carrier signal varies according to the instantaneous amplitude of the message signal.

The embedded system generates:
- Carrier Signal
- Message Signal
- Modulated Output Signal

The output waveform is observed and analyzed using an oscilloscope.

## Output

The project successfully generates:

- Carrier waveform
- Modulating waveform
- Amplitude Modulated waveform

Waveforms are visualized using an oscilloscope for analysis.
